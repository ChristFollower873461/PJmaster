# Update Checklist

Use this before publishing changes.

1. Read the changed files.
2. Confirm no private data is included.
3. Run `make qa`.
4. Review `dist/PJmaster-disc-manifest.txt`.
5. Open `print/PJmaster-CD-label.pdf`.
6. Commit with a clear message.
7. Push to GitHub.
8. If a physical disc or printed label exists, decide whether it needs replacement.
